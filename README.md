# MayoueBeauty509

Cloud-native e-commerce platform built with modern DevOps and AWS technologies.

## Project

MayoueBeauty509 is a hands-on DevOps implementation of a production-style
e-commerce platform running on Amazon EKS.

The project demonstrates infrastructure as code, containerization,
Kubernetes, CI/CD, GitOps, monitoring, centralized logging, security,
and AWS networking.

## Architecture

The platform will be deployed on Amazon EKS using Terraform-managed AWS
infrastructure.

CI/CD will use Jenkins, while ArgoCD will provide GitOps-based deployment
to Kubernetes.

Monitoring will use Prometheus, Grafana, and Alertmanager.

Centralized logging will use Filebeat, Elasticsearch, and Kibana.
